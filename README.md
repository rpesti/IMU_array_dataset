Raw measurement data associated with the manuscript:

**Robot-Aided Joint Calibration and Fusion of MEMS Gyroscope Array: A Novel Optimization-Based Method**

This repository contains the raw measurement data used for the experimental evaluation of a robot-aided calibration and sensor-fusion framework for a five-sensor MEMS gyroscope array.
The sensor array was rigidly mounted on the end effector of a calibrated UR5 robotic arm. The robot was used to generate repeatable three-dimensional motion, while the gyroscope, accelerometer and robot orientation data were recorded.

Sampling frequency: 80 Hz

Authors: Richard Pesti, Peter Sarcevic, Akos Odry
